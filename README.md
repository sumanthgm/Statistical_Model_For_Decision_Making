# Statistical Modelling for Decision Making — Notebooks

Coursework from the M.Tech Data Science & AI programme at PES University.

| Notebook | Topic |
| --- | --- |
| `Smdaproject.ipynb` | **Course project:** descriptive statistics, hypothesis testing (z-test, chi-square, one-way ANOVA) and OLS on the UCI *Productivity Prediction of Garment Employees* dataset |
| `Session_1_Descriptive_Statistics.ipynb` | Measures of central tendency and dispersion |
| `Session_1_Take_Home_Questions_(1).ipynb` | Take-home exercises |
| `Practice.ipynb` | Practice exercises |

Dataset: UCI Machine Learning Repository — *Productivity Prediction of Garment Employees*.
Data paths point to the author's Google Drive; download the dataset and update the path before running.

**Stack:** Python, pandas, NumPy, SciPy, statsmodels, seaborn, Matplotlib.
